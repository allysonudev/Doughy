# Doughy — App Store screenshots

Automated, localized, device-framed App Store screenshots via fastlane. The app's
UI tests drive the screens; fastlane captures them in every language and adds a
device frame + headline caption.

> This file is hand-written. `fastlane/README.md` is auto-generated by fastlane and
> gets overwritten on every run — keep notes here, not there.

## ⚠️ Must run in a real terminal

`fastlane snapshot` shells out to `xcodebuild` through a pseudo-terminal (PTY). Run
it from Terminal.app / iTerm — a real interactive shell. It will NOT work in an
environment without a TTY (you'll see `can't get Master/Slave device` or
`Pseudo Terminal Setup Error`). That's the only reason the full run wasn't done for
you in-session — the assistant sandbox lost its TTY partway through.

## Run

```sh
cd /Users/allyson/workspace/Doughy
bundle install                      # once
bundle exec fastlane screenshots    # capture all locales + frame (~40 min)
```

Output: `fastlane/screenshots/<locale>/` — raw `*.png` and framed `*_framed.png`,
plus a `screenshots.html` contact sheet.

## Captions (DRAFT — please review)

Each locale has `fastlane/screenshots/<locale>/title.strings` with the 4 headlines,
machine-drafted and marked `DRAFT`. Edit the wording to match your tone, then
re-apply without recapturing:

```sh
bundle exec fastlane frame_all_locales
```

Keep exactly one space around `=` in `title.strings` — frameit's parser rejects
alignment padding.

## What's configured

- **Devices** (Snapfile): iPhone 17 Pro Max (6.9"), iPad Pro 13-inch (M5).
- **Languages**: all 16 app locales.
- **Fonts** (`fastlane/screenshots/fonts/`): Poppins for Latin scripts; Noto Sans
  JP / KR / Arabic / Devanagari for `ja` / `ko` / `ar-SA` / `hi`. Each locale's
  `Framefile.json` points at the right one. Arabic and Hindi shape correctly
  (verified directly through ImageMagick's HarfBuzz rendering).
- **Background**: cream `background.jpg`; caption color `#412402`.

## Known limitations

- **iPad framing**: fastlane's frame library has no bezel for M4/M5 iPads, so iPad
  shots are captured **raw** (no frame/caption). Still valid App Store uploads at
  native resolution. iPhone gets the full framed + captioned treatment.
- Only the captions need localizing — the app UI is already localized, so the
  captures themselves are fully in-language.

## App Store Connect upload

Use the dedicated upload lane once the screenshots look right:

```sh
bundle exec fastlane ios upload_screenshots
```

That lane uploads screenshots only, targets App Store version `1.1`, clears the
existing screenshot set first, and leaves metadata + the binary alone.

If you ever need a different version number, pass it explicitly:

```sh
bundle exec fastlane ios upload_screenshots app_version:1.2
```

## App Store Connect upload caveats

- **Norwegian**: captured as `nb`; App Store Connect's locale code is `no` — route
  that folder automatically during upload.
- **Icelandic (`is`)**: captured for preview, but App Store Connect has no
  Icelandic storefront localization, so the upload lane skips it.
- **File selection**: the upload lane sends framed iPhone screenshots and raw iPad
  screenshots, so App Store Connect gets one clean set per device family instead
  of both framed and unframed iPhone variants.
